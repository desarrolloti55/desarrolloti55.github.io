# Software life cycle processes

### ISO/IEC/IEEE 12207:2017-11

Este documento escribe la etapas, procesos y documentos que sigue el desarrollo del un proyecto de software.


### Enfoque 
Definicion de necesidades de un stakeholder y funcionalidad, documentacion, la sintesis de diseño ([design syntesis](?file=Proyectos-Fases-no1-Definicion-de-Proyecto.md))
