# JSON Web Token (JWT)

[JWT Debugger](https://www.jwt.io/)

https://datatracker.ietf.org/doc/html/rfc7519

JSON Web Token (JWT) es un método compacto y seguro para URL que permite representar
declaraciones que se transferirán entre dos partes. Las declaraciones en un JWT
se codifican como un objeto JSON que se utiliza como carga útil de una estructura JSON Web Signature (JWS) o como texto plano de una estructura JSON Web Encryption (JWE), lo que permite que las declaraciones se
firmen digitalmente o se protejan con un código de autenticación de mensajes (MAC) y/o se cifren.
