Es un enfoque arquitectonico donde una aplicacion se divide en pequeños servicios independientes, especializados y funcionales, que se comunican entre si mediante protocolos ligeros como REST, facilitando el desarrollo agil, escalable y dsplieque en contenedores.

### REST 

Representational State Transfer (REST) No es un protcolo ni un estanda, es un estilo arquitectonico para diseñar aplicaciones en red

Principios rectores:

1. Uniform Interface - Interfaz uniforme
2. Client-Server
3. Statless - Apatrida
4. Cacheable - Amacenable en cache
5. Layered System - Sistema de capas
6. Code on Demand - Codigo bajo demanda
