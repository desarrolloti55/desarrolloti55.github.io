# Design Synthesis

*2026-02-16*

La síntesis de diseño (design synthesis) es el proceso creativo y estructurado de reunir información, insights de investigación y requisitos para formar un todo cohesionado, **convirtiendo ideas abstractas en soluciones concretas**. 

Es el paso entre la investigación y la ideación, donde se organizan los hallazgos para identificar patrones, temas y oportunidades. 


Pasos para Realizar la Síntesis de Diseño

* Organizar y Agrupar (Affinity Diagramming).
* Podar y Priorizar (Pruning).
* Interpretar y Crear Insights.
* Redefinir el Problema.
* Desarrollar Conceptos de Solución.
