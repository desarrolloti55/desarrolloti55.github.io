# desarrolloti55.github.io

Carta de presentación personal. Sitio estático (HTML y CSS) publicado con GitHub Pages en
<https://desarrolloti55.github.io>.

## Estructura

- `index.html`: contenido de la página.
- `assets/css/styles.css`: estilos, con tema claro y oscuro automático.

## Uso local

Abrir `index.html` en el navegador. No requiere compilación.
